# Portfólio — Leonardo Ferreira

Protótipo de site de portfólio pessoal, feito em HTML, CSS e JS puro.

## Estrutura

- `index.html` — conteúdo e seções (hero, sobre, serviços, projetos, contato)
- `style.css` — estilo, tema escuro, animação do pre-loader
- `script.js` — lógica do pre-loader e ano dinâmico no rodapé

## Rodando localmente

Basta abrir `index.html` no navegador, ou rodar um servidor local:

```bash
python -m http.server 8080
```

e acessar `http://localhost:8080`.
